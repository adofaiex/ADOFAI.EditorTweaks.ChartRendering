ADOFAI.EditorTweaks.ChartRendering

这是独立的谱面视频渲染 Mod。编辑器优化和压缩包功能不在此 Mod 中。

开始使用

  1. 在 UMM 中启用 Mod。
  2. 按设置面板中的快捷键打开 Web UI，默认是 Ctrl+Shift+E。
  3. 选择摄像机或游戏画面模式，设置输出目录和编码参数。
  4. 点击开始渲染；渲染期间可以查看进度或取消。

模式区别

摄像机模式适合干净的高分辨率谱面画面；游戏画面模式捕获最终游戏窗口，渲染期间不要改变窗口大小。

排查

如果渲染失败，请查看 Web UI 显示的结果路径和工作区中的 render.log，确认 ThirdParty/FFmpeg/ffmpeg.exe 存在。
